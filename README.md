\# DA\_LTDD\_FourBee



\## 1. Giới thiệu dự án

Ứng dụng kiểm tra trắc nghiệm giáo dục dành cho học sinh cấp 1, cấp 2 và cấp 3.



Ứng dụng được phát triển trên nền tảng Android bằng Kotlin, sử dụng API Server để trao đổi dữ liệu.



\## 2. Thành viên nhóm

| STT | Họ và tên | Vai trò |

|---|---|---|

| 1 | Thành viên 1 | Chưa phân công |

| 2 | Thành viên 2 | Chưa phân công |

| 3 | Thành viên 3 | Chưa phân công |

| 4 | Thành viên 4 | Chưa phân công |



\## 3. Công nghệ sử dụng

\- Android: Kotlin

\- IDE: Android Studio

\- Backend: API Server

\- Database: Chưa xác định

\- Quản lý mã nguồn: Git và GitHub



\## 4. Cấu trúc dự án

\- Source/: Mã nguồn ứng dụng và API Server.

\- Doc/: Tài liệu phân tích, thiết kế và đặc tả API.

\- Report/: Báo cáo và tài liệu quá trình thực hiện.



\## 5. Quy trình làm việc

\- main: Phiên bản ổn định của dự án.

\- develop: Nhánh phát triển chung.

\- feature/\*: Nhánh phát triển chức năng riêng của từng thành viên.
